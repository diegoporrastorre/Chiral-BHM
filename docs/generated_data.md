# Generated numerical datasets

`bdg_right_absorber.json` and `bdg_right_reflection.json` record the N=100 right-only boundary search with an exactly unchanged left core. The first is produced by `src/bdg_right_absorber.py` (73 spectral cases, 160/260-digit checks); the second by `src/analyze_right_absorber.py` (100/160-digit modal-reflection solves and transparent-load verification). Joint coefficient tapers, pure extra-loss layers, and combined cases are explicitly distinguished. See `derivations/bdg_right_absorbing_boundary.md` and `notebooks/bdg_right_absorber.ipynb`. No nearly perfect static absorber is claimed from this finite search.

`bdg_long_boundaries.json` is generated by the resumable `src/bdg_long_boundaries.py`. It extends the same joint pairing/detuning taper to N=128,256,512, comparing fixed N0=8 with N0=N/8 and N0=N/5. It stores high-precision spectral-abscissa brackets, higher-precision full Routh root counts, central profile values, and the number of sites within 1% of the original bulk coefficients. See `derivations/bdg_long_boundary_scaling.md` and `notebooks/bdg_long_boundaries.ipynb`. No long-chain double-precision eigenvalues are used to set these thresholds.

`bdg_damped_boundaries.json` is generated by `src/bdg_damped_boundaries.py`. It studies Rassaert-inspired tanh envelopes for the Delta=0.1 fixed BdG chain, comparing joint pairing/detuning suppression with a detuning-only control. It includes 120/200-digit characteristic-polynomial/Routh stability thresholds, raw double-precision conditioning diagnostics, physical impulse evolution, zero-frequency singular values, and central-profile deviations from the original bulk. See `derivations/bdg_rassaert_damped_boundaries.md` and `notebooks/bdg_damped_boundaries.ipynb`. This prescribed quadratic adaptation does not reproduce the paper's nonlinear stationary background or introduce additional boundary loss.

`quantum2023_detuned.json` is generated by `src/sweep_quantum2023_detuned.py`. It repeats the Quantum 2023 loss sweep with Delta=0.1, including a high-precision finite-OBC characteristic recurrence and Routh counts, full-matrix conditioning checks, infinite-bulk local-response quadrature, SVD topology, and finite-chain impulse evolution. See `derivations/quantum2023_detuned_stability.md` and `notebooks/quantum2023_detuned.ipynb`. Uniform loss shifts are exact; raw long-chain double-precision eigenvalues are not used for the reported stability thresholds.

`quantum2023_kappa.json` is generated by `src/sweep_quantum2023_kappa.py` for gs=gc=J=1, Delta=0, phi=pi/2, P=0 in the Quantum 2023 dynamical-matrix convention (kappa is the paper's gamma). It records the loss sweep, determinant winding at reference frequency zero, finite-chain singular values, exact/channel-preserving spectra, raw full-Nambu eigenvalue diagnostics, and propagator checks. See `derivations/quantum2023_kappa_stability.md` and `notebooks/quantum2023_kappa.ipynb`. Raw full-basis eigenvalues are deliberately retained as a numerical-conditioning diagnostic; they are not trustworthy stability estimates at this defective endpoint.

`data/generated/` stores reproducible numerical output and is excluded from git. Persistent research conclusions and parameter records belong in tracked derivations and results documents; figures belong in `figures/`.

`bdg_phi_sweep.json` is produced by `src/sweep_bdg_phase.py`. It records fixed quadratic parameters, phases in degrees, lossless bulk and PBC growth rates, OBC eigenvalues for N=40,80,120,160, dominant eigenvalue condition numbers and residuals, candidate saddle positions, pinch-tracking refinement differences, Fourier-integral fits, and transition locations. Rates are in units J=1. Subtract gamma=0.35 to obtain growth rates for the plotted lossy chain. This is not a stationary mean-field dataset.

`bdg_boundary_counterexample.json` records phi=80 degrees, gamma=0.1 and finite-OBC eigenvalue and time-domain checks at N=40,80,120. The second figure panel uses gamma=0.1; both panels use the same lossless spectrum dataset.

`bdg_topology_stability.json` is generated by `src/compare_topology_stability.py` (which reads the phase-sweep dataset). It records zero-frequency winding, exact topological phase intervals, minimum bulk singular gaps, finite-chain singular values and left/right localization, and a nonzero reference-frequency check. See `derivations/svd_topology_and_bulk_stability.md` and `notebooks/bdg_topology_stability.ipynb`.

Reproduction from the project root with dependencies from `requirements.txt`:

```powershell
python src/sweep_bdg_phase.py
```

For the current project-local Windows environment:

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
& 'C:\Users\usuario\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -c "import sys,runpy; sys.path.insert(0,'.local-deps'); sys.path.insert(0,'src'); runpy.run_path('src/sweep_bdg_phase.py',run_name='__main__')"
```

The notebook `notebooks/bdg_phi_sweep.ipynb` loads the saved dataset for inspection and plotting and provides an optional recomputation cell. No random initial conditions or covariance evolution are used.
